## Описание программы
Movie Library - это десктопное приложение для управления личной коллекцией фильмов с графическим интерфейсом на Tkinter. Программа позволяет добавлять, удалять, фильтровать и сохранять информацию о фильмах в удобном табличном формате.

### Основные функции
- 📝 Добавление фильмов с указанием названия, жанра, года выпуска и рейтинга
- 🗑 Удаление выбранных фильмов с подтверждением
- 💾 Автоматическое и ручное сохранение в JSON файл
- 🔍 Фильтрация по жанру и году выпуска
- 📊 Отображение всех фильмов в таблице с сортировкой
- 🔄 Автоматическая загрузка данных при запуске
- ✅ Валидация всех входных данных
- 📱 Адаптивный интерфейс с изменяемым размером окна

## Возможности
### Полный функционал управления:
1. **Добавление фильмов:**
   - Ввод названия (обязательное поле)
   - Ввод жанра (обязательное поле)
   - Ввод года выпуска (1888-2027)
   - Ввод рейтинга (0-10)

2. **Удаление фильмов:**
   - Выбор из таблицы
   - Подтверждение удаления

3. **Фильтрация:**
   - По жанру (частичное совпадение)
   - По году (точное совпадение)

4. **Сохранение/Загрузка:**
   - Автосохранение при каждом изменении
   - Ручное сохранение через кнопку
   - Загрузка при старте программы

5. **Дополнительные функции:**
   - Двойной клик для просмотра информации
   - Автоочистка полей после добавления
   - Информационные сообщения о действиях

## Примеры использования
1. Добавление книги
2. Заполните поля:
3. Название: "Побег из Шоушенка"
4. Жанр: "Драма"
5. Год: "1994"
6. Рейтинг: "9.3"
7. Нажмите "➕ Добавить фильм"
8. Получите подтверждение "✅ Фильм успешно добавлен!"

### Фильтрация
1. **Пример 1 - По жанру:**
- В поле "По жанру" введите "драма"
- Нажмите "🔍 Применить фильтр"
- Результат: покажет все фильмы жанра "Драма"
2. **Пример 2 - По году:**
- В поле "По году" введите "2020"
- Нажмите "🔍 Применить фильтр"
- Результат: покажет все фильмы 2020 года

### Сохранение и загрузка
1. **Автосохранение**: происходит после каждого добавления/удаления
2. **Ручное сохранение**: нажмите "💾 Сохранить в JSON"
3. **Автозагрузка**: при запуске программы

### Удаление
1. Кликните на фильм в таблице для выделения
2. Нажмите "🗑 Удалить выбранный"
3. Подтвердите удаление в диалоговом окне

## Валидация данных
### Проверки при добавлении фильма:
**Название**
- Не может быть пустым"
- "❌ Название фильма не может быть пустым!"

**Жанр**	
- Не может быть пустым	
- "❌ Жанр не может быть пустым!"

**Год**	
- Целое число от 1888 до текущего+1	
- "❌ Год должен быть целым числом!"
- Не может быть раньше 1888	
- "❌ Год не может быть раньше 1888!"

**Рейтинг**
- Число от 0 до 10	
- "❌ Рейтинг должен быть в диапазоне от 0 до 10!"

### Примеры корректных данных:
- Название: "Начало"
- Жанр: "Фантастика"
- Год: 2010 
- Рейтинг: 8.8

### Примеры НЕкорректных данных:
- Название: "" (пусто)
- Год: "abc"
- Год: "1800" (слишком рано)
- Рейтинг: "11" (выше 10)
